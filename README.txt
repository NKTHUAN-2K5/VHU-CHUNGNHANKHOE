WEB APP TẠO GIẤY CHỨNG NHẬN THÀNH TÍCH SINH VIÊN

Cách dùng:
1. Giải nén thư mục.
2. Mở index.html bằng Chrome/Edge.
3. Nhập Họ tên, MSSV, Khoa rồi bấm Xuất PDF từng sinh viên.
4. Muốn xuất hàng loạt: nhập mỗi dòng theo định dạng Họ tên, MSSV, Khoa hoặc chọn file TXT, CSV, TSV, XLS, XLSX rồi bấm Xuất nhiều sinh viên thành 1 file PDF.
5. Hỗ trợ tối đa 700 sinh viên mỗi lần xuất. File Excel lấy dữ liệu ở sheet đầu tiên; có thể có hàng tiêu đề.
6. Cần Internet để tải thư viện jsPDF và thư viện đọc Excel từ CDN.

Mẫu nền được tạo từ file SVK.pptx người dùng cung cấp, bỏ 3 ô chữ tên mẫu để thay bằng thông tin nhập.
